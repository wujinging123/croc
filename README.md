# Croc PULP SoC 学习报告
## 一、论文与项目简介
Croc是面向教育设计的片上系统（SoC），属于PULP项目的一部分，由苏黎世联邦理工学院与博洛尼亚大学联合开发。项目提供一套完整的芯片设计全流程代码，从RTL硬件描述、软件程序，到后端版图脚本，学生可以完整体验数字芯片从设计到流片的全过程。
该项目在2024完成流片，验证了这套开源教育芯片设计流程的可行性，降低芯片设计入门门槛。

## 二、前端（Frontend）工作
芯片前端，是**逻辑设计与仿真验证**，不关心芯片物理版图。
1. 使用Verilog/SystemVerilog（RTL）描述硬件电路，定义处理器、总线、外设等模块逻辑；
2. 搭建仿真环境，编写测试程序，在电脑上模拟电路运行，检查逻辑是否正确；
3. 功能仿真、编译软件，例如本次任务的hello world程序，验证CPU能否正常运行软件。
> 简单理解：前端 = 画逻辑电路图 + 软件仿真验证功能。

## 三、后端（Backend）工作
芯片后端，是**物理版图实现**，把前端的逻辑转换成真实芯片布局。
1. 布局布线：把各个硬件模块摆放到芯片晶圆上，连接信号线；
2. DRC/LVS检查：检查版图是否符合工厂工艺规则，保证版图和逻辑一致；
3. 生成GDSII版图文件，交付晶圆厂流片制造。
> 简单理解：后端 = 在硅片上安排硬件的位置和走线，生成可以交给工厂生产的图纸。

## 四、学习总结
通过Croc项目了解到，一块芯片的诞生分为前端逻辑仿真与后端物理设计两大阶段。前端负责验证芯片“逻辑对不对”，后端负责把逻辑变成能生产的物理版图。这个开源项目为集成电路专业学生提供了完整的芯片设计全流程学习平台。
